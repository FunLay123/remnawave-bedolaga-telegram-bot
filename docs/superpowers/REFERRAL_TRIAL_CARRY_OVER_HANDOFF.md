## Обязательные решения

- В схеме `days_only` переносится только неиспользованный реферальный остаток, а не базовый триал.
- Формула: `max(0, end_date - max(now, base_trial_end_date))`, точность до секунд.
- Пример: 3 базовых дня +20 реферальных +30 купленных = 50 дней, не 53.
- Реферальный бонус приглашённого, уже включённый при создании триала, входит в переносимый хвост.
- `add_reward_days` не меняет `is_trial` и `base_trial_end_date`.
- После оплаты обычная существующая конверсия в платную подписку сохраняется.
- Старые записи с `base_trial_end_date IS NULL` сохраняют прежнее поведение; backfill не делать.
- Схема `levels` и правила для обычного платного продления не меняются.
- Сейчас один тариф: не добавлять новые multi-tariff сценарии или поддержку переноса с нескольких триалов.
- Без новой env-настройки.

## Как выполнять

Использовать skill `superpowers:using-git-worktrees` для изоляции, затем `superpowers:subagent-driven-development`.

Выполнить две задачи последовательно, не параллельно:

1. Один implementation-агент выполняет Task 1 плана; отдельный reviewer проверяет его diff.
2. Один implementation-агент выполняет Task 2 плана; отдельный reviewer проверяет его diff.
3. После исправлений — финальный whole-diff reviewer и регрессионные тесты из плана.

Не сокращать обязательные ревью и не считать отчёт implementation-агента доказательством успеха без реальных тестов.

## Известные технические особенности

- Текущая последняя миграция: `0136_referral_first_purchase_marker_unique.py`; новая — `0137`.
- Для nullable timestamp использовать `AwareDateTime()` в модели и `sa.DateTime(timezone=True)` в миграции.
- При создании триала бонус приглашённого приходит через `get_effective_trial_days`; базовая дата должна исключать именно фактически применённый бонус.
- Необходимо охватить центральный `extend_subscription`, revive истёкшего триала, прямой bot flow, Mini App и cabinet.
- Основной риск: same-tariff продление может посчитать базовый триал повторно, а revive — отсчитать покупку от старого общего `end_date`.
- Не менять реферальные награды за первую покупку, их ledger и post-commit синхронизацию.
